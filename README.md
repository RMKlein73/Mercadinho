🛒 Sistema Mercadinho

Sistema desenvolvido para gerenciamento de produtos, categorias e fornecedores de um mercadinho.

🎨 Prototipação

A interface do sistema foi prototipada no Figma, representando as principais telas e fluxos de navegação, incluindo o gerenciamento de produtos, categorias e fornecedores.

Protótipo: [https://www.figma.com/design/oUS9TvokrDDDIRe0AadXXM/Untitled?node-id=0-1&t=I54fttqNBWBbmZle-1]
